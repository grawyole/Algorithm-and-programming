Дано: p > 0 — ціна одиниці товару; n > 0 — кількість одиниць; 0 ≤ d ≤ 100 — знижка у відсотках
Знайти: C — вартість покупки після знижки
Модель: C0 = pn — вартість без знижки; D = C0·d / 100 — сума знижки; C = C0 − D
Алгоритм:
  1. Ввести ціну p.
  2. Ввести кількість n.
  3. Ввести знижку d.
  4. Обчислити вартість без знижки: C0 ← p·n.
  5. Обчислити суму знижки: D ← C0·d / 100.
  6. Обчислити кінцеву вартість: C ← C0 − D.
  7. Вивести C.
  8. Кінець.
Тести:
p = 80, n = 5, d = 25 - C = 300
p = 12.5, n = 4, d = 15 - C = 42.5
p = 250, n = 2, d = 100 - C = 0 (крайній випадок: знижка 100%)
