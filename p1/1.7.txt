Дано: v — швидкість (км/год); t — час (год); q — витрата (л на 100 км)
Знайти: L — шлях (км), F — витрата (л)
Модель: L = vt; F = Lq / 100
Алгоритм:
  1. Ввести v, t, q.
  2. Якщо v ≤ 0, t < 0 або q ≤ 0, вивести помилку і завершити.
  3. L ← vt
  4. F ← Lq / 100
  5. Вивести L, F.
  6. Кінець.
Тести:
(90, 3, 6) - L = 270 км, F = 16.2 л
(50, 1.5, 9) - L = 75 км, F = 6.75 л
(120, 0, 8) - L = 0 км, F = 0 л
